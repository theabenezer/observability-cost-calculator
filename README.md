# Observability cost calculator

Prospect-facing calculators that compare what an observability platform costs at public list prices with the same coverage on IBM Concert, powered by IBM Instana and IBM Turbonomic. Each calculator is a single HTML file with IBM Carbon styling and no backend: nothing a prospect enters leaves the browser.

| Page | Compares |
|------|----------|
| `observability-cost-calculator-datadog.html` | Datadog vs IBM Concert |
| `observability-cost-calculator-dynatrace.html` | Dynatrace vs IBM Concert |
| `observability-cost-calculator-datadog-dynatrace.html` | Datadog or Dynatrace vs IBM Concert |
| `observability-cost-calculator-all-platforms.html` | Datadog, Dynatrace, New Relic, Grafana Cloud or Splunk Observability vs IBM Concert, with the net benefit of Observe + Optimize |

`index.html` links to the four pages and is what GitHub Pages serves.

List prices were read from each vendor's own pricing pages and billing documentation (checked 18 to 23 October 2026) and are footnoted on every page. The pages are estimates for conversation, not quotes.
